I'm **Mohamed Nagy**, a Systems-Oriented Cyber Intelligence Builder — Cybersecurity Architect & Threat Intelligence Engineer. I run the **Dr Robot** YouTube channel, where I teach tech and cybersecurity in Arabic — Black Hat Python, Bash, Ruby and Rust, malware, bug bounty and forensics.

I don't just use tools — I understand systems from the inside: how they work, how they fail, how they can be attacked, how to detect it, what evidence remains, and how to automate the investigation. I build open-source security tooling and intelligence platforms, and I document real work in public — paper results only, no invented numbers.
